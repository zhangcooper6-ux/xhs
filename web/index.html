❓ 使用说明

      
    

    

      
基本流程

      
    
        
  1. 在「输入源」分组填写小红书/抖音 URL 或本地文件路径
    2. 
        
  2. 从顶部「预设方案」选一个最接近需求的模板
    3. 
        
  3. 在各分组里微调参数（鼠标悬停可见详细说明）
    4. 
        
  4. 右侧「命令预览」实时显示对应的 CLI 命令
    5. 
        
  5. 点击底部「运行」启动，右侧日志区实时显示执行过程
    6. 
        
  6. 完成后「产出文件」分组列出最新输出
    7. 
      

      
智能提示

      
    
        
  • 必填项未填会在命令预览下方红字提示
    • 
        
  • 互斥参数同时开启会高亮警告（如 OCR 模式 / 颜色检测模式）
    • 
        
  • 依赖参数未满足时，相关子参数会自动禁用（灰色）
    • 
        
  • API Key 输入框旁有 ⚠️ 安全提示：仅当前会话有效，建议优先用环境变量
    • 
      

      
键盘快捷键

      
    
        
  • Ctrl+Enter 运行
    • 
        
  • Ctrl+. 停止
    • 
        
  • / 聚焦搜索框
    • 
      

      
启动方式

      
python web_ui.py
# 浏览器访问 http://localhost:5000
